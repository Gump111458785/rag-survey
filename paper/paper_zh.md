# 检索增强生成（RAG）大语言模型系统：架构、基准与前沿综述

**匿名作者**  
*双盲同行评审中*

---

### 摘要
大语言模型（LLMs）在自然语言推理与通用对话中表现突出，但其静态参数化记忆存在事实幻觉、知识衰退以及无法访问私有动态数据的固有缺陷。**检索增强生成（RAG）** 通过将生成过程锚定在外部非参数化知识库上，已成为解决上述缺陷的核心技术范式。本文对当前 RAG 研究版图展开全面系统的综述梳理。我们将 RAG 技术演进归纳为三大阶段：*基础 RAG（Naive RAG）*、*高级 RAG（Advanced RAG）* 与 *模块化 RAG（Modular RAG）*；构建了涵盖查询重构、混合多阶段检索、交叉重排与上下文压缩的核心模块功能分类法；系统汇总了 RGB、MultiHop-RAG、ARES 与 RAGAS 等评测基准与能力指标体系；最后总结了超长上下文窗口竞争、多模态知识对齐与可信溯源审计等关键开放挑战。

---

### 1. 本综述三大核心贡献
1. **三阶段层次化系统架构分类法**：系统确立了 Naive RAG、Advanced RAG 与 Modular RAG 的三级分类体系，为复杂检索生成系统的模块化解耦与工程设计提供标准参照。
2. **多维能力评估基准与指标体系大盘梳理**：系统分析了 15+ 核心量化指标与 6 大代表性评测基准套件（RGB、MultiHop-RAG、ARES、RAGAS 等），涵盖忠实度、召回率、噪声鲁棒性与否定拒答能力。
3. **技术挑战与前沿发展路线图展望**：深度剖析长上下文模型与 RAG 的互补权衡、多模态图文融合、边缘端低延迟约束与对抗注入防御等未来演进路径。

### 2. 核心架构与基准对比全景

#### 表 1：三大 RAG 架构范式对比分析
| 核心维度 | 基础 RAG (Naive) | 高级 RAG (Advanced) | 模块化 RAG (Modular) |
|:---|:---:|:---:|:---:|
| **控制流** | 刚性线性流水线 | 多阶段顺序管道 | 动态 DAG / 状态机自适应路由 |
| **检索时机** | 生成前单次单步 | 生成前多路混合检索 | 迭代式、主动触发或按需检索 |
| **分块与索引** | 固定长度机械切块 | 语义分块与层级索引 | 知识图谱与多源异构联邦索引 |
| **上下文优化** | 粗暴拼接 Top-$k$ | 神经重排序与上下文剪枝 | 记忆辅助与选择性信息提炼 |
| **反思纠错机制** | 无 | 基础过滤规则 | 主动反思、幻觉校验与引用溯源 |
| **运行开销系数** | 低 ($\approx 1\times$) | 中等 ($\approx 2.5\times$) | 动态可变 ($3\times$–$6\times$) |

#### 表 2：主流 RAG 评测基准评测维度
| 评测基准 | 核心评测能力 | 主要知识领域 | 评测形式 |
|:---|:---|:---:|:---:|
| **RGB** | 噪声鲁棒性、否定拒答率、反事实抗干扰 | 维基百科、新闻 | 黑盒测试集 |
| **MultiHop-RAG** | 多跳推理、多文档信息合成、实体跳转 | HotpotQA, MuSiQue | 推理路径匹配 |
| **CRUD-RAG** | 增删改查全生命周期问答操作 | 医疗、金融 | 多任务综合语料 |
| **ARES** | 上下文相关性、答案忠实度、答案相关度 | KILT, PubMed | 大模型判官+合成验证 |
| **RAGAS** | 忠实度、上下文召回率、语义相似度 | 通用问答 | 自动化指标评测库 |
